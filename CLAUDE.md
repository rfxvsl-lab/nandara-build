# Instruksi untuk Claude Code

Baca [`AGENTS.md`](./AGENTS.md) dan [`dokumentasi.md`](./dokumentasi.md) sebelum bekerja di repo ini.

## Aturan commit (keputusan pemilik repo)

- **Jangan** menambahkan baris atribusi AI ke commit atau pull request: tidak ada `Co-Authored-By: Claude …`, tidak ada `Claude-Session: …`, tidak ada "Generated with Claude Code".
- Pesan commit cukup menjelaskan perubahan.
